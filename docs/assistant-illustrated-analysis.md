# 国画助手图文赏析发布说明

图文赏析由 Web 和 Critic 一起提供。`qwen3-vl-plus` 在赏析正文中返回局部坐标，Web 按当前问题的附件顺序定位原画，并把局部和讲解并排显示。Core 保留已有的回复父消息关系和附件顺序，本轮只增加针对这两个约定的回归测试。无需数据库迁移、模型密钥变更或新增服务。

## 发布顺序

1. 按各仓库的正常流程合入 `main`，通过 `main` 到 `release` 的 PR 生成正式制品。发布前从助手模型注册表核对 `qwen3-vl-plus` 已配置、已启用并支持图片。使用当前环境的已批准配置和制品绑定。
2. 按现有 Web 发布流程先部署支持两种局部坐标格式的 Web。这样在 Critic 更新前，历史回复和现有坐标格式仍可显示。
3. 使用现有 [R25 AI 发布流程](../r25/AI_RELEASE_CONTRACT.md) 发布 Critic 候选制品。此次变更在源码提示词，沿用已批准的模型注册表和 Core 私有配置摘要。Core 回归测试本身无需单独切换生产 JAR。
4. 选用 `qwen3-vl-plus`，上传一张获准用于测试的图片并询问意象。验证正文与局部对应，点击局部能打开原图，刷新后仍绑定同一轮问题的图片。桌面和手机各验一次，并检查旧格式回复、文字追问和模型返回无效坐标的情况。

## 回退

如需回退本次功能，先按 R25 AI 流程恢复 Critic，再评估 Web 回退。含新坐标格式的已保存回复需要支持两种格式的 Web 才能继续显示局部，保留兼容版 Web 可保留这些回复的完整图文展示。
